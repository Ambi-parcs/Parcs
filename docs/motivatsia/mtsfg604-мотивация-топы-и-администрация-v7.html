📋 Инструкции по должностям — что заполнять

🤝 РОП — руководитель отдела продаж (банкеты)

Где расчёт: вкладка «🤝 Ком. служба» → окно «Администрация» → должность «РОП». Ежемесячно вносится только «Факт» по трём KPI (план и веса не трогать):

  • Полный банкетный оборот ⭐ (45%) — сумма банкетов, проведённых и полностью оплаченных за месяц, ₽. Авансы предстоящих мероприятий не включаются.
  • Рентабельность банкетов (35%) — доход по банкетам минус согласованные прямые расходы, ₽.
  • Качество предоставленных услуг (20%) — доля положительных отзывов, 0–1 (например 0,95).

Порядок работы: сверить реестр банкетов от МПП → исключить незакрытые и авансовые мероприятия → передать три цифры расчётчику → после внесения проверить статус «✅ Расчёт готов» и свой лист во вкладке «🔐 Кабинет».

Стоп-факторы (допуск = 0): фальсификация статусов банкетов или оплат; включение авансов до проведения праздника.

Пример: план 27 000 000 ₽, факт 25 000 000 ₽ (92,6% → коэффициент 0,852), рентабельность и качество по плану (1,00) → Kрез = 0,933 → премия = 80 000 × 0,933 ≈ 74 700 ₽.

🧑‍💼 МПП — менеджер по продажам (готовит данные для расчёта РОП)

Что сдать за месяц (в первый рабочий день месяца, следующего за расчётным):

  • Реестр банкетов: клиент, дата, сумма, статус (проведён / перенесён / отменён), оплаты (аванс, доплата, полная оплата).
  • Оборот для KPI РОП: только проведённые и полностью оплаченные банкеты; авансы и незакрытые мероприятия — отдельным списком с пометкой.
  • Отзывы: обратная связь по каждому проведённому банкету + доля положительных.
  • Изменения после проведения (допуслуги, возвраты) — только с подтверждающими документами.

Контроль качества данных: сумма реестра сходится с кассой и безналом по банкетам; расхождение — уточнить до передачи РОП.

Мотивация МПП: если для МПП заведена отдельная схема — она создаётся в окне «Администрация» кнопкой «➕ Добавить должность» (задать личный код); порядок внесения фактов тот же, что у РОП.

🎡 Управляющий парком (Вегас · Колумбус · Хорошо · Океания)

Где расчёт: вкладка «🤝 Ком. служба» → окно своего парка → должность «Управляющий парком». Ежемесячно вносится только «Факт» (план и веса не трогать):

  • Выполнение плана ⭐ (35%) — фактические доходы парка за месяц, ₽ (сверка с финансовым отчётом).
  • Операционный результат парка (30%) — операционная рентабельность парка, ₽.
  • Операционный аудит парка (20%) — итоговая оценка выездной проверки по чек-листу (безопасность, исправность, чистота, сервис), 0–1. Вносит проверяющий руководитель.
  • Клиентский сервис (15%) — доля положительных отзывов за период, 0–1.
  • Продажи мерчендайзинга (прямая мотивация) — факт продаж мерча, ₽. Премия — доля от факта: <60% плана → 0%; от 60% → 1%; от 90% → 2%; от 100% → 3%.

Порядок работы: собрать данные парка (доходы, операционный результат, отзывы, продажи мерча) → передать расчётчику → расчётчик вносит факт и оценку аудита → проверить статус и свой лист в «🔐 Кабинет».

Стоп-факторы (допуск = 0): подтверждённое грубое нарушение безопасности; сокрытие происшествия; работа критически неисправной зоны вопреки запрету.

Шкалы: результативные KPI — ниже 80% → 0; 80% → 0,5; 90% → 0,8; 100% → 1,0; ≥110% → 1,2 (между точками пропорционально). Аудит — 0,8 → 0,5; 0,9 → 0,8; 0,95 → 1,0; 1,0 → 1,1 (ступенчато). Главный KPI ⭐ ниже 80% → Kрез не выше 0,50.

Пример (Вегас): план 25 млн → факт 26 млн (104% → 1,08), операционный результат и сервис по плану (1,00), аудит 0,95 (→ 1,00) → Kрез = 1,028 → премия = 50 000 × 1,028 = 51 400 ₽; мерч 500 000 при плане 600 000 (83% → 1%) = 5 000 ₽; итоговая ЗП = 130 000 + 51 400 + 5 000 = 186 400 ₽.

Параметры топ-менеджмента (Генеральный директор, Финансовый директор, Бренд-шеф, Бар-менеджер) заполняются на вкладке «📊 Параметры», их описание — на вкладке «📖 Описание системы». Коммерческий директор — вкладка «🎯 Ком. директор».

🧮 Как считаются результаты

Топы: Мотивация = Оклад + Фикс.мотивация × KPI; KPI — средневзвешенное по факторам; стоп-фактор обнуляет KPI.

Excel-модель (Ком. директор и Ком. служба): Премия = Целевой бонус × Kрез × Допуск; прямой мерч — доля от фактических продаж.

Окладники: Мотивация = Оклад + Фикс.мотивация (KPI = 1).

📖 Описание системы мотивации

Общие принципы начисления

Мотивация = Оклад + (Фикс. мотивация × KPI)

KPI рассчитывается как средневзвешенное значение коэффициентов факторов:

KPI = Σ(коэффициентᵢ × весᵢ) / Σ(весᵢ)

Каждый коэффициент ограничивается диапазоном [0; 1]. Каждый фактор вносит пропорциональную долю в переменную часть.

Стоп-факторы при срабатывании обнуляют KPI (пороги настраиваются на вкладке «Параметры»).

Для административных сотрудников (окладников) KPI = 1, стоп-факторы не применяются.

Распределение по юрлицам:

  • «Обе» → оклад делится поровну между Амбиленд и Амбирест, переменная часть начисляется только в Амбиленд.
  • «Амбиленд» → всё начисляется в Амбиленд.
  • «Амбирест» → всё начисляется в Амбирест.

Коэффициенты факторов:

  • План/факт: коэффициент = min(1; факт / план).
  • Шкала 0–100%: коэффициент = min(1; значение / 100).
  • Оценка 0–5: коэффициент = min(1; оценка / 5).
  • Food-cost (диапазон 25–30%): коэффициент = (30 − факт) / (30 − 25), ограничен [0; 1]. 25% и ниже → 1.0; 30% и выше → 0.
